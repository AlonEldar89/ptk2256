# Electra Sirkin Project Viewer

A React-based web application for viewing and selecting apartments in the Electra Sirkin project. This interactive viewer allows users to:

- View different buildings in the project
- Select and view floor plans
- See detailed apartment information including:
  - Prices
  - Apartment sizes
  - Number of units available

## Technology Stack

- React
- TypeScript
- Material-UI (MUI)
- CSS-in-JS styling

## Project Structure

```
src/
├── components/     # React components
├── App.tsx        # Main application component
└── index.tsx      # Application entry point
```

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm start
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Features

- Interactive building selector
- Dynamic floor plan viewer
- Real-time apartment details display
- Responsive design for all screen sizes
- RTL (Right-to-Left) support for Hebrew text
